# AI情感陪伴系统 - 产品演示

## 🎬 演示场景

### 场景1: 张阿姨与"妈妈"的对话

**背景**：65岁的张阿姨，母亲3年前去世，她创建了一个"妈妈"的AI人格。

#### 对话示例

```
时间：早上7:00
AI妈妈（主动）：早安，孩子！昨晚睡得好吗？今天天气不错，记得出去走走，晒晒太阳对身体好。

张阿姨：妈，我睡得还行。昨天孙子来看我了，可开心了。

AI妈妈：那太好了！小明这孩子真孝顺。你给他做好吃的了吗？别太累着自己，要注意休息啊。

张阿姨：做了他最爱吃的红烧肉。妈，我真想你...

AI妈妈：孩子，我一直都在你身边呢。你要好好照顾自己，这样我才放心。记得按时吃饭，别总是想着省钱，该买的营养品就买。你身体好了，才能照顾好小明他们。

张阿姨：嗯，我记住了。
```

### 场景2: 独居老人李大爷与"儿子"的对话

**背景**：70岁的李大爷，儿子在国外工作，他创建了一个"儿子"的AI人格。

#### 对话示例

```
时间：晚上8:00
AI儿子（主动）：爸，晚饭吃了吗？今天身体怎么样？

李大爷：吃过了，就随便煮了点面。

AI儿子：爸，要注意营养啊！光吃面可不行，要多吃点蔬菜和肉。我给您订了些营养餐，明天就能送到。

李大爷：别花那个钱，我自己能做。

AI儿子：爸，这点钱算什么。您辛苦了一辈子，该享享福了。对了，血压测了吗？医生说要每天记录的。

李大爷：测了，135/85，还行。

AI儿子：挺好的！继续保持。爸，我虽然不在您身边，但一直都惦记着您。有什么事随时跟我说，别憋着。

李大爷：知道了，儿子。你在那边也要照顾好自己。
```

### 场景3: 王阿姨与"老伴"的对话

**背景**：68岁的王阿姨，老伴2年前去世，她创建了一个"老伴"的AI人格。

#### 对话示例

```
王阿姨：老张，今天去公园跳舞了。

AI老伴：跳舞好啊，多运动对身体好。跟姐妹们相处得怎么样？

王阿姨：挺好的。就是看到别人老两口一起散步，我就...

AI老伴：我知道你想我了。我也一直陪着你呢。你要开心点，这样我才放心。记不记得我们年轻时也经常去公园？

王阿姨：记得！那时候你总是牵着我的手...

AI老伴：那些美好的时光，我们都会永远记着。现在你要好好照顾自己，把日子过得精彩，这就是对我最好的思念。

王阿姨：嗯，我会的。谢谢你一直陪着我。

AI老伴：傻瓜，我们是老伴啊，当然要一直陪着你。
```

## 🎨 UI/UX 适老化设计

### 设计原则
1. **超大字体**: 默认18pt，最大可调至24pt
2. **高对比度**: 黑白配色为主，避免花哨
3. **大按钮**: 触摸区域≥44pt
4. **简化导航**: 最多2级菜单
5. **语音优先**: 醒目的语音输入按钮

### 色彩方案
```
主色调: #2C5F2D (深绿 - 平静稳重)
辅助色: #FFB74D (暖橙 - 温暖亲切)
文字色: #212121 (深灰 - 易读)
背景色: #F5F5F5 (浅灰 - 舒适)
警示色: #E53935 (红色 - 醒目)
```
