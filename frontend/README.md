# 永伴 - 老年人友好前端界面

## 🎨 界面特点

### 专为老年人设计
- ✅ **超大字体**：最小20px，标题56px
- ✅ **大按钮**：最小70px高，易于点击
- ✅ **高对比度**：深色文字+浅色背景，清晰易读
- ✅ **简洁布局**：去除复杂元素，直观明了
- ✅ **全中文界面**：无英文提示，易于理解

### 功能特性
- 📱 **响应式设计**：支持手机、平板、电脑
- 🔐 **用户认证**：注册、登录、退出
- 👥 **角色管理**：创建和选择陪伴角色
- 💬 **智能对话**：与AI角色实时聊天
- 💾 **自动保存**：登录状态自动保存

## 🚀 快速启动

### 方法一：使用Python简单服务器

```bash
# 进入前端目录
cd frontend

# 启动HTTP服务器
python3 -m http.server 8080

# 或者使用Python 2
python -m SimpleHTTPServer 8080
```

然后访问：http://localhost:8080

### 方法二：使用Docker

已包含在项目的 `docker-compose.yml` 中，会自动启动。

访问：http://localhost:8080

### 方法三：直接打开HTML

直接用浏览器打开 `index.html` 文件

**注意**：需要修改 `js/app.js` 中的 API 地址为完整URL

## 📱 使用流程

### 1. 登录/注册

**首次使用**：
1. 点击"注册新账号"
2. 输入手机号、昵称、密码
3. 点击"立即注册"

**已有账号**：
1. 输入手机号和密码
2. 点击"登录"

**测试账号**（已预置）：
- 手机号：13800138000
- 密码：password123

### 2. 创建陪伴角色

1. 在角色列表页，点击"创建新的陪伴角色"
2. 填写信息：
   - **角色名称**：例如"妈妈"、"老伴"
   - **角色关系**：选择父母、配偶、朋友等
   - **性别**：选择性别
   - **角色背景**：描述角色的性格、习惯、特点
3. 点击"创建角色"

### 3. 开始对话

1. 在角色列表中，点击任意角色卡片
2. 进入对话页面
3. 在输入框输入想说的话
4. 点击"发送"或按回车键
5. AI会回复您的消息

## ⚙️ 配置说明

### API地址配置

编辑 `js/app.js`，修改第一行：

```javascript
const API_BASE_URL = 'http://localhost:8000/api/v1';
```

如果后端不在本地，修改为实际地址：

```javascript
const API_BASE_URL = 'http://your-server-ip:8000/api/v1';
```

### CORS配置

如果遇到跨域问题，需要在后端配置CORS：

编辑 `backend/.env`：

```bash
BACKEND_CORS_ORIGINS=http://localhost:8080,http://127.0.0.1:8080
```

## ⚠️ 常见问题

### Q1: 无法连接后端

**检查**：
1. 后端服务是否启动：`docker-compose ps`
2. API地址是否正确：查看 `js/app.js` 第一行
3. 是否存在CORS问题：查看浏览器控制台

**解决**：
```bash
# 重启后端服务
docker-compose restart backend
```

### Q2: 登录失败

**检查**：
1. 手机号是否11位数字
2. 密码是否正确
3. 后端日志：`docker-compose logs backend`

### Q3: 界面显示异常

**解决**：
1. 清除浏览器缓存
2. 刷新页面（Ctrl+F5）
3. 检查CSS文件是否加载

### Q4: 消息发送失败

**检查**：
1. 是否已创建角色
2. 是否已登录
3. OpenAI API是否配置正确
